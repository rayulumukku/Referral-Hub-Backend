# 🚀 START YOUR PROFESSIONAL REFERRAL SYSTEM NOW!

## ⚡ **QUICK START - 3 SIMPLE STEPS!**

### **Step 1: Start Backend Server** 🖥️

```bash
cd BACKEND
npm start
```

**You should see:**
```
✅ MongoDB Connected
🚀 Server running on port 5001
```

---

### **Step 2: Start Frontend** 🎨

Open a NEW terminal/command prompt:

```bash
cd FRONTEND
npm start
```

**You should see:**
```
Compiled successfully!
Local: http://localhost:3000
```

---

### **Step 3: Open Browser** 🌐

Go to: **http://localhost:3000**

1. **Login** with your account (or create one)
2. **Click "🔍 Data View"** in the top navigation bar
3. **See EVERYTHING!**
